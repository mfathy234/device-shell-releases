# DeviceShell releases

Downloads for **DeviceShell**, a lightweight Windows 10/11 shell add-on: a replacement taskbar, a hover notch with tools, and battery rings for your mouse, keyboard, headset, controller and laptop.

Get the latest build from [Releases](https://github.com/mfathy234/device-shell-releases/releases/latest):

- `DeviceShell-Setup-<version>.exe`: installer (per-user, no admin needed)
- `DeviceShell-<version>-win-x64.zip`: portable copy

Each file has a matching `.sha256` checksum. DeviceShell's built-in updater checks this repository and verifies the checksum before installing.
